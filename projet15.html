API REST avec FastAPI

Création d'une API REST complète avec authentification et base de données PostgreSQL

Description du Projet

API REST moderne et performante développée avec FastAPI, offrant des endpoints pour gérer des ressources avec authentification JWT, validation de données et documentation automatique. L'API suit les meilleures pratiques RESTful et inclut des tests unitaires complets.

Le projet démontre une architecture propre avec séparation des couches (routes, services, modèles) et utilise SQLAlchemy pour l'ORM.

Fonctionnalités Principales

  • Authentification JWT avec refresh tokens
  • CRUD complet pour plusieurs ressources
  • Validation automatique avec Pydantic
  • Documentation interactive (Swagger/ReDoc)
  • Gestion des erreurs et logging
  • Pagination et filtrage des résultats
  • Rate limiting et CORS configurables
  • Tests unitaires et d'intégration
  • Déploiement avec Docker

Technologies Utilisées

FastAPI Python PostgreSQL SQLAlchemy Pydantic JWT Docker Pytest
