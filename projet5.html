Création d'un site en HTML et CSS

Développement d'un site web portfolio avec HTML, CSS et JavaScript.

Description du Projet

Ce projet consistait à créer un site web portfolio complet en utilisant les technologies web fondamentales : HTML5, CSS3 et JavaScript. L'objectif était de concevoir une interface moderne, responsive et accessible.

Le site inclut plusieurs sections : page d'accueil, à propos, projets, compétences et contact. Une attention particulière a été portée au design, à l'expérience utilisateur et aux performances.

Technologies utilisées

  • HTML5
  • CSS3
  • JavaScript
  • Responsive Design

Fonctionnalités implémentées

  • Design responsive (mobile, tablette, desktop)
  • Navigation fluide avec smooth scroll
  • Animations CSS et JavaScript
  • Formulaire de contact fonctionnel
  • Galerie de projets interactive
  • Optimisation SEO
