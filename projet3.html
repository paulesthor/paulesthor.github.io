Classification Douanière & IA

Modèle de Machine Learning XGBoost / TF-IDF et application web ONNX pour prédire automatiquement la classification douanière de produits industriels.

Contexte & Problématique

Dans le cadre de mon alternance chez Legrand (Département R&D / Data), j'ai été confronté aux limites des bases de données traditionnelles et à la complexité des classifications douanières. Chaque nouveau produit industriel doit se voir attribuer un code douanier précis (HS Code à 10 chiffres) pour transiter aux frontières. Cette tâche, historiquement manuelle, fastidieuse et sujette aux erreurs, ralentissait le processus de commercialisation.

Pour y remédier, j'ai développé de manière autonome un modèle d'intelligence artificielle capable de prédire automatiquement le code douane d'un produit à partir de sa description textuelle (PIM) et de ses caractéristiques techniques complexes (norme ETIM). Ce projet m'a permis d'agir en interface directe avec les directions métiers et R&D.

Stack & Approche Technique

Le pipeline de données a été codé entièrement en Python avec les librairies phares de la Data Science :

  • XGBoost Classifier : Modèle de gradient boosting d'arbres de décision configuré avec arrêt précoce (early stopping) et gestion des classes déséquilibrées.
  • Scikit-learn : Utilisation de TfidfVectorizer pour transformer le texte brut en matrice sparse (réduisant la consommation de RAM par 3) et enrichissement du vocabulaire (25 000 n-grams).
  • Passeport Technique Boosté : Feature engineering combinant les libellés multilingues (FR/EN) et les données techniques structurées (norme ETIM) avec pondération dynamique (coefficients x3 sur les specs critiques comme l'ampérage, la tension ou le nombre de pôles).
  • ONNX Runtime Web : Exportation du modèle au format ONNX pour permettre son exécution directe dans le navigateur, éliminant le besoin de serveurs d'API complexes.

Résultats & Impact

Grâce à des choix méthodologiques forts (comme le passage d'un INNER JOIN strict à un LEFT JOIN enrichi sur les données ETIM, augmentant le volume d'entraînement de 71 %, et le filtrage rigoureux des codes fictifs), le modèle a atteint des métriques de haute performance :

  • Top-1 Accuracy (précision exacte) : Prédiction du code exact à hauteur de 82.4% sur le jeu de test.
  • Top-3 Accuracy (dans les 3 premiers) : Présence du vrai code dans les 3 premiers choix suggérés à 91.2%.
  • Top-5 Accuracy (dans les 5 premiers) : Présence dans les 5 choix à 94.7%.
  • Inférence Client (In-Browser) : Intégration de l'inférence ONNX directement dans le navigateur en JavaScript, permettant d'exécuter l'IA hors-ligne sans serveur.
