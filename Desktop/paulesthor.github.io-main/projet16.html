Détection de Fraudes Bancaires

Modèle de machine learning pour détecter les transactions frauduleuses en temps réel

Description du Projet

Système de détection de fraudes utilisant des algorithmes de machine learning pour identifier les transactions suspectes en temps réel. Le modèle analyse des millions de transactions et détecte les anomalies avec une grande précision tout en minimisant les faux positifs.

Le projet traite le problème des données déséquilibrées (très peu de fraudes par rapport aux transactions légitimes) avec des techniques de rééchantillonnage et d'ajustement des seuils de décision.

Fonctionnalités Principales

  • Détection d'anomalies avec Isolation Forest
  • Classification avec Random Forest et XGBoost
  • Gestion des données déséquilibrées (SMOTE)
  • Feature engineering avancé
  • Évaluation avec métriques adaptées (F1, AUC-ROC)
  • Prédictions en temps réel
  • Dashboard de monitoring des fraudes
  • Système d'alertes automatiques
  • Analyse des patterns de fraude

Technologies Utilisées

Python Scikit-learn XGBoost Pandas imbalanced-learn Streamlit
