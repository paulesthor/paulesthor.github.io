Système de Recommandation de Films

Algorithme de filtrage collaboratif pour recommander des films basé sur les préférences utilisateur

Description du Projet

Système de recommandation intelligent utilisant le filtrage collaboratif et le filtrage basé sur le contenu pour suggérer des films aux utilisateurs. Le modèle analyse les notes et préférences des utilisateurs pour identifier des patterns et proposer des recommandations personnalisées.

Le projet utilise le dataset MovieLens et implémente plusieurs algorithmes de recommandation pour comparer leurs performances.

Fonctionnalités Principales

  • Filtrage collaboratif user-based et item-based
  • Recommandations basées sur le contenu (genres, acteurs)
  • Système hybride combinant plusieurs approches
  • Matrice de factorisation (SVD, ALS)
  • Évaluation des performances (RMSE, précision)
  • Interface web pour tester les recommandations
  • Gestion du problème de cold start
  • Recommandations en temps réel

Technologies Utilisées

Python Scikit-learn Surprise Pandas Flask NumPy
