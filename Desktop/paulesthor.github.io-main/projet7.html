Analyse de données avec Python

Projet d'analyse de données utilisant Pandas, NumPy et Matplotlib pour visualiser des tendances.

Description du Projet

Ce projet d'analyse de données en Python avait pour objectif d'explorer un jeu de données complexe, d'identifier des patterns et de créer des visualisations pertinentes pour communiquer les insights découverts.

Le projet couvre l'ensemble du pipeline d'analyse de données : de l'importation et du nettoyage des données jusqu'à la visualisation finale et l'interprétation des résultats.

Technologies utilisées

  • Python
  • Pandas
  • NumPy
  • Matplotlib
  • Seaborn

Analyses réalisées

  • Importation et nettoyage des données
  • Analyse exploratoire des données (EDA)
  • Calcul de statistiques descriptives
  • Détection et traitement des valeurs aberrantes
  • Création de visualisations (graphiques, heatmaps)
  • Identification de corrélations entre variables
