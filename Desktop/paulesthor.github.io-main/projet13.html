Mon Portfolio

Développement "Custom" sans framework pour une performance et une identité maximales

Le Contexte

Un portfolio de développeur est souvent le projet le plus dur à réaliser. Il faut éviter :

  • Les templates génériques vus 1000 fois.
  • La surenchère technique (utiliser React pour un site statique).
  • Le manque de personnalité.

Choix Technique : Vanilla Core

J'ai fait le choix radical de n'utiliser aucun framework (ni React, ni Vue, ni Bootstrap).

  • Performance : Le site charge instantanément (Score Lighthouse 100/100).
  • Maîtrise : Je montre ma compréhension profonde du DOM et du CSS Natif.
  • Maintenance : Pas de dépendances npm à mettre à jour chaque semaine.

L'Animation de Fond

L'arrière-plan topographique n'est pas une vidéo (trop lourde), mais une génération procédurale en temps réel sur un Canvas HTML5.

J'utilise l'algorithme "Marching Squares" couplé à du bruit de Perlin (Simplex Noise) pour créer ces courbes de niveau fluides qui réagissent doucement, sans drains excessifs de batterie.
