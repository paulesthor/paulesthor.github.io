Modèle de régression linéaire

Modèle R pour prédire les prix immobiliers en Deux-Sèvres à partir de données historiques.

Description du Projet

Ce projet de machine learning avait pour objectif de développer un modèle de régression linéaire capable de prédire les prix de l'immobilier dans le département des Deux-Sèvres. Le modèle utilise des données historiques de ventes immobilières pour identifier les facteurs influençant les prix.

L'analyse inclut l'exploration des données, la sélection des variables pertinentes, la construction du modèle et son évaluation avec différentes métriques de performance.

Technologies utilisées

  • R
  • ggplot2
  • dplyr
  • caret

Étapes du projet

  • Collecte et nettoyage des données immobilières
  • Analyse exploratoire des données (EDA)
  • Feature engineering et sélection de variables
  • Construction du modèle de régression linéaire
  • Validation et évaluation (R², RMSE, MAE)
  • Visualisation des résultats et des prédictions
